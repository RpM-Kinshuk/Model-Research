# Scale-Up Research

This directory tracks the handoff from preliminary research into the scale-up phase.

At a glance:

- Phase 1 curation and Phase 2 analysis are operationalized in `Model-Zoo`
- Phase 3 experiments and reports live in `Model-Research`

Operational source of truth:

- curated tables: `Model-Zoo/data/curated/`
- analysis outputs: `Model-Zoo/analysis_runs/phase2/`

`Model-Research` owns the HTSR v3 study and frozen reports that consume those
operational inputs. See `docs/HTSR_STUDY.md` for the current method and evidence.

For the actual phase-2 run shape, use:

- `Model-Zoo/docs/operations/analysis.md`

Use this directory for scale-up-facing research notes, summaries, and report links. Do not treat it as the canonical home for curated tables or analysis outputs.
