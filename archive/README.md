# Archive

This directory preserves older material that is not part of the active HTSR v3 workflow.

Contents:

- `reference-work/`: paper snapshots, older drafts, and related materials
- `correlation_runs/`: older correlation analysis outputs
- `research_runs/`: superseded studies retained only when needed for provenance
- `scripts/`: archived script wrappers preserved for provenance and reference

These are provenance references, not part of the supported study or dashboard.
